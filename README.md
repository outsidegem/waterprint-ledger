# 💧 WaterPrint Ledger Browser Extension

WaterPrint is an open-source AI resource governance tool that tracks estimated Watt-hours and milliliters of water used during your LLM interactions (ChatGPT/Gemini) and allows you to optimize prompts to save resources.

## How to Install on Your Device

You can install this extension directly from this repository on Chrome, Edge, or Brave using Developer Mode.

### Step 1: Download the Extension
1. Click the green **Code** button at the top right of this page.
2. Select **Download ZIP**.
3. Extract (unzip) the downloaded folder to a permanent location on your computer (e.g., your Documents folder).

### Step 2: Load into Your Browser

**For Google Chrome / Brave:**
1. Open your browser and navigate to `chrome://extensions/` (or `brave://extensions/`).
2. Toggle **Developer mode** ON (in the top right corner).
3. Click the **Load unpacked** button.
4. Select the extracted folder containing the `manifest.json` file.

**For Microsoft Edge:**
1. Open your browser and navigate to `edge://extensions/`.
2. Toggle **Developer mode** ON (in the left sidebar).
3. Click the **Load unpacked** button at the top.
4. Select the extracted folder.

### Step 3: Run WaterPrint
1. Pin the WaterPrint extension to your browser toolbar for easy access.
2. Open ChatGPT or Google Gemini.
3. Type a prompt and watch the WaterPrint HUD calculate your resource baseline in real-time!
